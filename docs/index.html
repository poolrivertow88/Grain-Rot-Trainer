It's co-op, so read this first

Two kinds of option

GRAIN ROT is PvE with no anti-cheat, no PvP and no leaderboards, so nothing here is about beating other players. But it's a shared session for up to 20 people.

  • Client-side — field of view, brightness, free camera, hide HUD, third person, no voice distortion. Invisible to everyone else.
  • Tagged crew — freezing the Corrupted, extracting from anywhere, Rot level, dungeon modifiers, loot surviving death. These change the run for the whole descent.

Host-only mode ships enabled and greys out crew options when you're a guest. Leave it on unless you're hosting. A crew making bad decisions together is the entire game — removing the danger from someone else's descent without asking removes their game, not just yours.

Two game bugs this fixes

Not cheats — repairs

Negative room EXP. Outpost rooms can drop below zero EXP and stall progression. Fix negative room EXP clamps the value at zero. On by default.

Saves breaking across updates. The game is patching quickly after a strong launch and some players have lost Outpost progress. Rolling save backup copies your save every 10 minutes into slots the game doesn't provide. Also on by default.

Both are game-side issues the developers may fix. Check their patch notes before assuming you still need these — and run the trainer in read-only mode if these two are all you want from it.

Install in four steps

  1. Download and unblockRight-click the zip, Properties, tick Unblock, Apply. Windows quarantines downloads and the trainer won't attach otherwise.
  2. Extract outside Program FilesDocuments or the desktop is fine. A protected folder breaks profile saving.
  3. Start the game and get into the Outpost or a runDescent options only bind once the elevator has taken you down to a floor.
  4. Run the trainer as administrator, press InsertThe header shows your host status and crew size. Turn off Steam Cloud while you experiment.

Questions

Will I get banned for using cheats in GRAIN ROT?

No. It is a PvE co-op game with no anti-cheat, no PvP and no leaderboards, so there is nothing to be banned from. The real risk is annoying the crew you are descending with.

How do I fix the negative room EXP bug in GRAIN ROT?

Fix negative room EXP in the Outpost tab clamps the value at zero, and it is enabled by default. This is a game-side bug that the developers may patch, so check their notes before assuming you still need it.

Can I get infinite gold in GRAIN ROT?

Yes, in the Loot tab, along with a gold multiplier, a furniture value multiplier and an instant Grinder that turns debris into gold with no wait.

How do I stop my Spark fading out in GRAIN ROT?

Spark never fades switches the timer off entirely. The fade timer slider is usually the better answer: stretch it to a few minutes and you keep the tension of being bodiless while getting a realistic chance to find a host.

Can I turn off the voice distortion in GRAIN ROT?

Yes, with No voice distortion in the Rot tab. It is client-side, so it changes nothing for your crew. Useful if you are playing with people speaking a second language or if you have any hearing difficulty.

Does the GRAIN ROT trainer work in multiplayer?

Yes, and GRAIN ROT is co-op only. Client-side options affect nobody else. Options tagged crew change the shared run, so use them with a group that knows. Host-only mode is enabled by default and blocks those options when you are a guest.
